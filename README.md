TypoTherapy — telegram-бот для исправления опечаток и автоматической типографической обработки текста: кавычки, тире, пробелы, знаки препинания, специальные символы и форматирование.

Regexps для опечаток взяты из «Викификатора» Википедии ([Gadget-wfTypos.js](https://ru.wikipedia.org/wiki/MediaWiki:Gadget-wfTypos.js) CC BY-SA 4.0) и переведены в формат Python.
